# 🔒 FocusLock

**FocusLock – Your Smart Study and Productivity Companion**

FocusLock is a student-focused productivity application built using Kodular.

## 🚀 Features

- Study and focus timer
- Productivity support
- Helps students manage study sessions
- Simple and user-friendly interface

## 🛠️ Technology Used

- Kodular Creator
- MIT App Inventor-based visual development environment

## 📦 Project File

The `.aia` file in this repository contains the editable Kodular source project.

## 🎯 Project Goal

To help students improve their concentration, manage their study time, and build better study habits.

## 👨‍💻 Developer

Created as a student project.

## 📌 Future Improvements

- Advanced focus timer
- Study statistics
- Daily study schedule
- Focus session tracking
